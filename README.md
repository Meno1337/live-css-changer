# 🎨 Live CSS Changer

Live CSS Changer — Chrome Extension для динамического изменения CSS в реальном времени прямо на любом сайте.

Позволяет мгновенно применять пользовательские стили без перезагрузки страницы.

---

## 🚀 Возможности

- ⚡ Мгновенное применение CSS
- 🌙 Переключение тёмной / светлой темы интерфейса
- 🧠 Умные быстрые пресеты (без дублирования кода)
- 📁 Сохранение пользовательских пресетов
- 🎛 Генератор тем (Dark / Light / High Contrast)
- 💾 Сохранение стилей отдельно для каждого домена
- 🧹 Быстрая очистка редактора с подтверждением
- 🧩 Встроенный редактор CodeMirror

---

## 📦 Установка

### 🔹 Способ 1 — Установка из релиза (рекомендуется)

1. Перейдите во вкладку **Releases** этого репозитория.
2. Скачайте последнюю версию (`live-css-editor-vX.X.zip`).
3. Распакуйте архив в любую папку.
4. Откройте Chrome и перейдите:

   chrome://extensions/

5. Включите **Режим разработчика** (в правом верхнем углу).
6. Нажмите **Загрузить распакованное расширение**.
7. Выберите распакованную папку.

✅ Расширение появится в панели Chrome.

---

### 🔹 Способ 2 — Установка из исходного кода

git clone https://github.com/Meno1337/live-css-changer.git

Затем:

1. Откройте chrome://extensions/
2. Включите режим разработчика
3. Нажмите **Загрузить распакованное расширение**
4. Выберите папку проекта

---

## 🛠 Использование

1. Откройте любой сайт
2. Нажмите на иконку расширения
3. Введите CSS в редакторе
4. Нажмите **ПРИМЕНИТЬ**

Изменения применяются мгновенно.

## 🔄 Обновление

Для обновления:

1. Удалите старую версию из chrome://extensions/
2. Скачайте новый релиз
3. Загрузите распакованную папку снова
