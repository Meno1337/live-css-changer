# 🎨 Live CSS Changer

Live CSS Changer — инструмент для динамического изменения CSS в реальном времени прямо в браузере.

---

## 🚀 Возможности

- ⚡ Мгновенное применение CSS без перезагрузки страницы  
- 🎯 Удобно для тестирования и отладки стилей  
- 🧪 Подходит для фронтенд-разработки  
- 🧩 Простая интеграция  

---

## 📦 Установка

```bash
git clone https://github.com/Meno1337/live-css-changer.git
cd live-css-changer
```

---

## 🛠 Использование

1. Запусти проект  
2. Открой страницу в браузере  
3. Изменяй CSS и смотри результат в реальном времени  

---
